# ADR 0001 — Session cookies and CSRF

Status: DOCUMENTED WORKING DESIGN / ASSUMPTION; reconciled PRD/Phase01/UD-001/002. Traces U02, A Security; D OQ-022/023 and §د. Context: frontend/backend separation must not expose credentials or delegate object authorization to UI.

Decision: one HTTPS browser origin through a trusted gateway; Django database-backed sessions. Use host-only `__Host-minhaai_session`, Path=/, Secure, HttpOnly, SameSite=Lax, no Domain attribute. Proposed inactivity 24 hours, absolute 7 days with server-side enforcement and rotation on login/privilege change; exact durations need security/product confirmation and do not come from the PRD. No localStorage JWTs. Django CSRF cookie `__Host-minhaai_csrf` Secure, HttpOnly, SameSite=Lax, Path=/; return masked token from safe no-store CSRF endpoint for header use. Django token verification and exact Origin/Referer allowlist protect every unsafe route including login/logout. Refresh token after login rotation; deny missing CSRF, no exemption for JSON.

Session identifies actor only; server rechecks verified email/adult/lifecycle/object roles, including worker commands. No shared caching of personalized responses. No public wildcard credentialed CORS. Gateway forwards original trusted host/origin correctly, strips forged headers and never logs cookies. Separate origins are a deferred alternative requiring strict credentialed CORS/cookie/CSRF tests, not an automatic production default.

Optional extension uses the explicit pairing/one-use code/PKCE/scoped in-memory token protocol in identity-and-extension-contracts.md; actual allowlists require G-EXT security review. That document also defines Google state/PKCE/nonce/safe-link/signup/MFA/recovery. No secret/session token is distributed to arbitrary pages, no content-script cookie access, no private-library or financial scopes.

Consequences: server revocation possible; database session cleanup required; SSR private responses avoid shared caches. Single origin requires reliable trusted ingress and cookie propagation; CSRF/cross-owner/admin-library tests are mandatory. Rejected alternative: browser bearer tokens in persistent JS-readable storage due to theft/revocation complexity. Legal age/leap-day boundary remains unresolved, not silently selected.
