## Minimal Public Free Beta slice and Advanced boundary

The usable minimum is approved public catalog/text search, verified adult identity, manual confirmed profile, deterministic eligibility, saves/application checklist/manual versions, internal notifications and human support, with immutable bounded Credits and configurable Admin policies. AI generation/extraction/matching/support, uploads/exports/ingestion and the Chrome extension are included only after their specific provider/scanner/source/site gates are satisfied; every unavailable feature offers a safe manual/unavailable path. Credits and daily limits never imply a paid API route. Semantic search remains required for Advanced MVP, replaceable/gated until an approved implementation meets quality/cost constraints; no vector DB mandate.

F-10/FR-080–088 and paid package activation remain off in Beta under explicit owner decision D §أ 1; manual paid workflow remains an Advanced MVP commitment. Official status feeds remain conditional FR-058. Additional geographies/languages/types/channels/AI chat editing are P2 or explicitly excluded until change control. The extension and support cannot be silently reclassified as post-MVP. The supplied PRD's original delivery phases differ from agent prompt numbering.
